## Social Security & Public Administration Platform

**A single governed system for running a national social insurance scheme —
registration, contributions, compliance, benefits, legal recovery, finance and
citizen communication — replacing legacy desktop systems and paper.**

---

### What it covers

| | |
|---|---|
| **Registration** | Insured persons, employers, dependants, employment and wage history |
| **Contributions** | Filing, assessment, penalties, receipting, cashiering, employer ledger |
| **Compliance** | Inspections, findings, violations, cases, payment arrangements, enforcement |
| **Legal** | Referral to judgment, cost recovery, maker-checker at every stage |
| **Benefits** | Products, eligibility, claims, awards, payments, medical review, life certificates, suspensions, overpayment recovery, mortality, means tests, uprating, appeals |
| **Finance** | Immutable ledgers, receipts, reconciliation, disbursement |
| **Communications** | Email, SMS, WhatsApp, printed letters, in-app, push, webhooks, voice/IVR — all from one governed hub |
| **Portals** | Claimant, employer, doctor and agent self-service |
| **Platform** | Roles, workflow, documents, audit, configuration governance, reporting |

### Why institutions choose it

- **Policy change without a code release.** Rates, products, formulas, penalty
  rules, letters and workflows are administered from screens, under approval.
- **Audit that actually answers questions.** Who did what, when, under which
  approval — including every letter, text and call sent to a citizen.
- **Enforced four-eyes.** Separation of duties is enforced by the database, not
  by procedure.
- **Nothing half-configured goes live.** Readiness gates block approval and say
  exactly what is missing.
- **A documented way off the legacy system.** Table-by-table migration mapping
  the client's own team can review.
- **Citizen self-service.** Portals plus an IVR that answers balance,
  contribution and claim-status calls without a human.

### Technology

Browser-based. React and TypeScript front end, PostgreSQL with row-level
security, serverless services, managed cloud hosting. No desktop install.
Provider-independent communication adapters.
